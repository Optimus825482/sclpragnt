# Plan: Audit / Olay Kayıt Sistemi

Uygulamaya, **kim ne zaman giriş yaptı, ne yaptı** bilgisini IP + cihaz bilgisiyle kalıcı kaydeden ve yalnız admin'in görebildiği DB tabanlı bir log sistemi ekliyoruz. Stack: Next.js frontend → FastAPI backend → PostgreSQL (ORM yok, ham SQL + `database.py` helper'ları). Mevcut `users`/`chart_forecasts` yapıları desen alınacak.

## Kapsam (varsayılan: kullanıcı eylemi odaklı)
- **Auth**: login başarılı/başarısız, logout, şifre değişimi, kullanıcı CRUD (admin), admin'in kendi profil şifresi
- **Kullanıcı eliyle yapılan işlemler**: Ayarlar kaydetme (`PUT /api/config`), manuel pozisyon kapatma (`POST /api/positions/{symbol}/close`), LLM/paper trading toggle'ları (`PUT /api/llm/paper-trading`, `auto-paper-trading`), `POST /api/llm/paper-trade`, manuel tarama (`POST /api/strategy/manual-scan`, `/api/radar/execute`), alarm kurma, monitoring ayar değişikliği
- Otonom bot döngüleri bu tabloya YAZILMAZ (zaten `decision_logs`/`trades`/`monitoring_notifications` var). Sadece **kullanıcı tetikli** olaylar.
- IP kaynağı: `X-Real-IP` (nginx, login throttle ile aynı desen), yoksa `request.client.host`. Her kayda: tam User-Agent + Accept-Language + gerçekleşen kategori/aksiyon + JSONB detay.

## 1) Veritabanı şeması — `backend/migrations/001_pgvector_schema.sql` (sona ekle)
```sql
CREATE TABLE IF NOT EXISTS audit_logs (
  id BIGSERIAL PRIMARY KEY,
  actor_username TEXT,
  actor_role TEXT,
  category TEXT NOT NULL,
  action TEXT NOT NULL,
  target TEXT,
  details JSONB,
  ip TEXT,
  user_agent TEXT,
  accept_language TEXT,
  created_at DOUBLE PRECISION NOT NULL
);
CREATE INDEX IF NOT EXISTS audit_logs_created_idx ON audit_logs(created_at DESC);
CREATE INDEX IF NOT EXISTS audit_logs_actor_idx ON audit_logs(actor_username, created_at DESC);
CREATE INDEX IF NOT EXISTS audit_logs_category_idx ON audit_logs(category, created_at DESC);
```
Startup `init_db()` bu dosyayı yeniden çalıştırdığından şema otomatik uygulanır; container'da `entrypoint.sh` de aynı. `reset_trading_data` allowlist'ine EKLENMEZ (loglar sıfırlamada korunur — admin sayfası temizleme butonu kendi DELETE'iyle siler).

## 2) DB helper'ları — `backend/app/database.py` (users blok hizasına)
- `_audit_row(row)` dönüştürücü (details JSONB → dict)
- `save_audit_log(actor_username, actor_role, category, action, *, target=None, details=None, ip=None, user_agent=None, accept_language=None)` — epoch `time.time()`, parametreli INSERT + commit
- `list_audit_logs(limit, offset, actor=None, category=None, action=None, q=None)` — parametreli filtre + `ORDER BY created_at DESC, id DESC`
- `count_audit_logs(...)` aynı filtrelerle
- `delete_audit_logs_before(before_ts)` (admin temizleme için)

## 3) Ortak istemci/cihaz bilgisi toplama — `backend/app/api_common.py`
- `client_context(request) -> dict` — `{ip, user_agent (kısaltılmış), accept_language}`; X-Real-IP + 512-char UA sınırı
- `log_user_action(...)` asenkron yardımcı — `database.save_audit_log` çağırır, **asla exception fırlatmaz** (loglama ana akışı bozmasın)
- Ana akışı bloklamasın diye route'larda `await log_user_action(...)` sıralı; kritik değilse `asyncio.create_task` — log DB hatası işlemi düşürmez

## 4) Login/auth kayıtları — `backend/app/main.py`
- `auth_login` (:250): başarısız → `LOGIN_FAILED`; başarılı (cookie set öncesi) → `LOGIN_SUCCESS`; login throttle ayrımı da kaydedilir. Aktör = denenmiş kullanıcı adı.
- `auth_logout` (:289) → `LOGOUT` (aktör: `_session_user`)
- `profile_update_password` (:223) → `PASSWORD_CHANGE`
- Admin user CRUD (:302-379): `USER_CREATE / USER_UPDATE / USER_DELETE` (target=username, details=rol/aktif değişimi); `PUT /api/admin/users/{id}`'de role değişimi ayrıca vurgulanır
- Global middleware'de `OPTIONS` ve public path'ler zaten hariç — route içi kayıtlar yeterli, middleware'e yük bindirmeyiz

## 5) Kullanıcı eylemi kayıtları (main.py + ilgili router'lar)
- `_apply_config_update` sonu (main.py:1360 civarı, `set_llm_setting` sonrası) → `CONFIG_UPDATE`, details: değişen anahtar sayısı; `market.reconnect_requested`/`universe_changed` bilgisi
- `POST /api/positions/{symbol}/close` → `POSITION_CLOSE_MANUAL`
- `PUT /api/llm/paper-trading` (1630) / `auto-paper-trading` (1636) → `PAPER_TRADING_TOGGLE`
- `POST /api/llm/paper-trade` (1643) → `PAPER_TRADE_OPEN` (sembol)
- `POST /api/strategy/manual-scan` (1876) → `MANUAL_SCAN`
- Alarm CRUD (main.py 700-730 civarı, `alert_rules`) → `ALERT_CREATE / ALERT_UPDATE / ALERT_DELETE`
- monitoring.py: `PUT /api/monitoring/settings` (82) → `MONITORING_SETTINGS_UPDATE`; `POST /api/monitoring/reset-notifications` (296) → `MONITORING_NOTIFICATIONS_RESET`
- Kategori sözlüğü: `auth`, `user`, `config`, `trade`, `alert`, `monitoring`

## 6) Admin-only listeleme API — `backend/app/main.py` (users blok yanına)
- `GET /api/admin/audit-logs` — `_require_admin(request)`; query: `limit` (≤500), `offset`, `actor`, `category`, `action`, `q`; yanıt `{"ok": True, "logs": [...], "total": n, "limit", "offset"}` (repo listeleme sözleşmesiyle aynı)
- `DELETE /api/admin/audit-logs` — body `{before_ts}` (varsayılan 30 gün) → silme; `{"ok": True, "deleted": n}`
