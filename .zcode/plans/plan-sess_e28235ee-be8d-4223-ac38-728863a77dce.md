## Amaç (grafik sayfası — 4 değişiklik)

1. **Chart arka planı varsayılan siyah** (`#000000`) — şu an `transparent` (container lacivert `#0f1131` gösteriyor).
2. **İndikatörler**: Tüm sembollerdeki kayıtlı indikatör yerleşimleri temizlenir; grafik **varsayılan olarak SlingShot** gösterir — **üçgenler olmadan** (kullanıcı "üçgenler görünmesin" dedi). Yani yalnız EMA50/EMA11 çizgileri (lime/red) overlay default. Kullanıcı yine kendi indikatörlerini ekleyebilir.
3. **Üst tahmin paneli (LLM'siz)**: Grafik üstünde, seçili TF'ye göre **ML fiyat tahmin modeli** çıktısı:
   - Beklenen fiyat tahmini (target_pct → hedef fiyat, hit_probability).
   - Sembolle ilgili **daha önce yapılmış tahminlerin başarı durumu** (doğru/yanlış, dokunma).
   - Aynı sembol **5 dk içinde** başka biri açtıysa/ürettiyse o tahmin gösterilir (cache).
   - **Yenile** ikonu — tıklayınca taze tahmin üretir (cache bypass).
   - Teknik analiz metni yok (kullanıcı "teknik analiz olmasa da olur" dedi).
4. **Tahmin kaydı**: Model tahminleri `chart_forecasts` tablosuna kaydedilir; ufuk dolunca M1 mumlarla ölçülür; ölçümler ML eğitimine journal olarak girer.

## Backend

### 1. Migration — `chart_forecasts` tablosu
`001_pgvector_schema.sql` sonuna:
```sql
CREATE TABLE IF NOT EXISTS chart_forecasts (
  id BIGSERIAL PRIMARY KEY,
  symbol TEXT NOT NULL,
  timeframe TEXT NOT NULL,
  horizon_minutes INTEGER NOT NULL,
  entry_price DOUBLE PRECISION NOT NULL,
  target_pct DOUBLE PRECISION NOT NULL,        -- model target (kesir değil yüzde? netleştirilecek)
  target_price DOUBLE PRECISION,
  hit_probability DOUBLE PRECISION,
  model TEXT, prompt_version TEXT,
  created_at DOUBLE PRECISION NOT NULL,
  status TEXT NOT NULL DEFAULT 'pending',       -- pending|evaluated
  evaluated_at DOUBLE PRECISION,
  outcome_price DOUBLE PRECISION,
  outcome_return_pct DOUBLE PRECISION,
  outcome_direction TEXT,
  direction_correct BOOLEAN,
  max_favorable_pct DOUBLE PRECISION,
  max_adverse_pct DOUBLE PRECISION,
  outcome_details JSONB
);
CREATE INDEX ... (symbol, created_at DESC); (status, created_at);
```

### 2. `ml_forecast` — sembol+TF bazlı özellikle tahmin
- Mevcut `predict_target(symbol, features, horizon)` yalnız `horizon∈{5,15}`; özellikler dışarıdan geliyor. Grafik paneli için backend, sembolün **güncel snapshot'ından** özellikleri toplayıp `predict_target`'i çağıran yeni bir akış kurar (scout'taki desen — `llm_chat.py:807`).

### 3. Yeni endpoint — `POST /api/chart/{symbol}/forecast`
- İstek: `{timeframe}` (veya URL'de).
- Akış:
  1. **5 dk cache** kontrolü: `(symbol, timeframe)` için son tahmin varsa ve `created_at` ≤5 dk ise onu döndür (paylaşılan tahmin). `fresh=1` ise cache bypass.
  2. Sembolün güncel teknik snapshot'ından ML özelliklerini topla → `ml_forecast.predict_target` (5 ve 15 dk ufukları).
  3. Tahmini `chart_forecasts`'a kaydet (status pending).
  4. Yanıt: `{symbol, timeframe, generated_at, forecasts: [{horizon_minutes, target_pct, target_price, hit_probability}], cache: {hit, age_sec}}`.
- `fresh=1` (yenile butonu) yeni tahmin üretir + yeni kayıt.

### 4. Sembol tahmin başarısı — `GET /api/chart/{symbol}/forecast-history`
- `chart_forecasts`'tan sembolün evaluated satırlarını döndür: `{total, evaluated, direction_correct_rate, target_hit_rate (max_favorable ≥ target), recent: [...]}`. Model eğitimine giren ölçümler.

### 5. Değerlendirme döngüsü
- `chart_forecast_evaluation_loop`: pending tahminlerin ufku (5/15 dk) dolunca `_forecast_outcome_from_closed_m1` benzeri M1 mumlarla ölç → `mark evaluated`. (Mevcut `llm_forecast_evaluation_loop`'tan ilham alır; `ml_forecast.train`'e journal olarak girebilmesi için ayrı okuma fonksiyonu.)

### 6. `database.py` fonksiyonları
`save_chart_forecast`, `get_recent_chart_forecast(symbol, timeframe, within_sec)`, `list_chart_forecasts(symbol, ...)`, `mark_chart_forecast_evaluated`, `get_pending_chart_forecasts`.

## Frontend (charts/page.tsx)

### 7. Arka plan siyah
`createChart` layout `background: { color: "transparent" }` → `#000000` (veya container'a siyah). Grid çizgileri koyu gri kalır.

### 8. SlingShot default indikatörü
- Yeni registry entry (IndicatorPicker `CUSTOM_INDICATOR_ENTRIES`): `sling_shot` — overlay, `calculate` EMA50 + EMA11 plot döndürür (üçgen/marker YOK).
- `loadIndicators()`/`loadFromDb` davranışı: grafik ilk açılışta (kayıtlı indikatör yoksa) default `[sling_shot]` ile gelir. Kullanıcı kendi ekledikçe localStorage/DB kaydı onu ezer. "Tüm sembollerdeki yerleşimleri temizle": chart_settings DB kayıtlarının indicators alanı boşsa default uygulanır — mevcut `loadFromDb` kayıtlı listeyi yüklüyor; temizlik için localStorage + DB'deki mevcut kayıtlı indikatörlerin gösterilmemesi gerek. En temizi: `sling_shot` default'u yalnız hiç indikatör yokken devreye sokmak; kullanıcı eski yerleşimlerini zaten DB'den yüklüyorsa "tümünü temizle" tek seferlik davranış netleştirilmeli.
